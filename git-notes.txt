git restore - вернет в старую версию файла, без нового коммита, 
git checkout <хеш> - переключает в старую версию проекта по указанному коммиту
HEAD detached - не знаю как описать если честно, по примеру поняла что это читая последнюю страницу книги продолжая писать книгу вернуться на ранние страницы чтобы посмотреть что было раньше
git revert - новым коммитом вернет старую версию файла именно по указанному коммиту 
git switch -c - создает новую ветку и переключает к нему сразу 
git merge - обьединяет изменения веток с текущей веткой 
fast-forward - еще не допоняла, чтобы описать 
git branch -d - удаляет ветку, после проверки с обьединением с main веткой
